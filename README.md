# Greeting Picker для SillyTavern

Вставляет в уже идущий чат любое приветствие из карточки (основное или альтернативное) вместо генерации нового сообщения.

## Установка

**Вариант 1 — вручную (подходит и для Termux):**
1. Распакуйте папку `SillyTavern-GreetingPicker`.
2. Положите её в:
   - новые версии ST: `SillyTavern/data/default-user/extensions/`
   - старые версии: `SillyTavern/public/scripts/extensions/third-party/`
3. Перезагрузите страницу ST. Проверьте, что расширение включено в Extensions → Manage extensions.

**Вариант 2 — через GitHub:** загрузите папку в свой репозиторий и вставьте ссылку в Extensions → Install extension.

## Использование

- Меню с волшебной палочкой (слева от поля ввода) → **Вставить приветствие**.
- Выберите режим:
  - **Добавить новым** — приветствие появится отдельным сообщением бота в конце чата;
  - **Заменить последнее** — последнее сообщение бота удаляется и заменяется приветствием.
- **Остальные приветствия — в свайпы**: у вставленного сообщения все приветствия карточки будут доступны свайпом влево/вправо. Свайп вправо после последнего варианта, как обычно, запустит генерацию.
- **Развернуть** — показать текст целиком перед вставкой.
- В групповом чате сверху появляется выбор персонажа.

Макросы `{{user}}`, `{{char}}` и т. п. подставляются автоматически.

## Слэш-команда (удобно для кнопок Quick Reply на телефоне)

- `/greeting` — открыть окно выбора
- `/greeting 0` — основное приветствие
- `/greeting 2` — альтернативное №2
- `/greeting mode=replace 1` — заменить последнее сообщение бота альтернативным №1
- `/greeting char=Имя 3` — для группового чата
